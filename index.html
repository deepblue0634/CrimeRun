操作

            
    
              
  • タッチ 左下の ◀ ▶ で左右、右下の「アクセル」「ブレーキ」。止まったままブレーキを押し続けると降車します。射撃は自動です。
    • 
              
  • キーボード ← → 左右 / ↑ アクセル / ↓ ブレーキ / C 乗り物の切替（タイトル画面） / Esc 設定
    • 
              
  • 徒歩 同じボタンで歩けます。▼の付いた乗り物に触れると乗り換えて体力が回復します。道の水色の板はターボです。
    • 
            

          

          

            
仕様との対応

            
    
              
  • 2層構造 位置・速度・当たり判定はすべて (X, Y) の2D矩形。描画の直前だけ Scale = 1 / (相対Y × 係数 + 1) で画面座標に変換します。
    • 
              
  • 直角カーブ マップ上のカーブ区間を、画面の1行ごとの横ずらし値として積み上げて道を曲げます。強さと長さは区間ごとに違います。自機は横Gを受けず、ドリフトの見た目とタイヤスモークだけが出ます。
    • 
              
  • ブラインドコーナー アウト側は崖や高い壁で隙間なく塞ぎ、イン側は建物を間引きます。
    • 
              
  • 乗り物 ジャンプ台で空中状態になり、地上の車との判定を無視します。マッスルカーは短いジャンプ、モトクロスバイクは大ジャンプです。
    • 
              
  • ロケット マッスルカーはアクセルを踏み直すとロケットランチャーを撃ちます（約1.3秒ごと）。ロックオン中の敵がいれば追尾し、着弾すると周りの車も吹き飛ばします。
    • 
              
  • ロックオン 自機の前方の扇状エリアに入った敵を0.35秒で捕捉し、自動で連射します。
    • 
              
  • ドリフトとターボ カーブ中のドリフトとターボ中は、ぶつかった車を弾き飛ばし、自機はダメージを受けません。
    • 
              
  • パトカー サイレンつきで、後ろ向きに発砲します。弾は2Dの小さな矩形で、空中では当たりません。
    • 
              
  • 起伏 道のアップダウンは描画だけの見た目で、内部の2Dに高さはありません。
    • 
            

          

          

            
MEGA ENGINE との対応

            
    
              
  • Z80 入力、自機の状態、当たり判定、スプライトの状態、効果音。
    • 
              
  • 68000 パトカーなどの動きと出現、道路・建物・乗り物の絵（Bitmap）の生成。
    • 
              
  • VDP Bitmap を1ラインずつ読み、そのラインだけの16色パレットに割り当てます。そのあとスプライト（2組のパレット）と文字パターンを重ねます。
    • 
              
  • パターン共有 星の絵はHUDでも回復の光でも同じで、パレットだけが違います。炎とターボの噴射、ロックオンの輪（緑と赤）も同じです。文字はHUDとポップアップで共有しています。
    • 
              
  • 未対応 回転（3回のシア）、ブリッターのコピー、Line Buffer の実体、64KBの容量制限、Z80と68000の実際の処理速度。
    •
